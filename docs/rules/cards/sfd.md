# Spiritforged (SFD) card scripts — wave R3

Lane: the `### Spiritforged` rows of `## Unscripted cards by set` in `docs/cards-coverage.md`
(215 cards). Scripts live in `packages/rules/src/cards/SFD/batch-*.ts` (shared builders and
lane-prefixed custom conditions/effects in `common.ts`); one behaviour test per card in
`packages/rules/test/cards/sfd/`.

## Summary

| partial                | 33    |
| manual                 | 21    |

Wave R4b upgraded every Equipment that only needed Equip (818.1.c.2), Quick-Draw (819), Weaponmaster
(821) or attached Effect Text (718.3/719.1), plus Jax, Unmatched's granted Quick-Draw and Fading
Memories' Temporary-on-gear: the rows for those capabilities were removed from the gap table below.
Temporary on an attached Equipment is inactive (718.2). The final integration pass flipped the 13
Repeat spells (including Feral Strength) to `implemented` once lane B's Repeat execution was in.

Status rules: `implemented` only when every line of the current text (errata applied) is
automated and tested; `partial` names exactly what is not automated and why; `manual` cards
resolve through the §6.4 manual window. Keywords the engine implements (Accelerate, Action,
Reaction, Hidden, Deflect, Ganking, Assault, Shield, Tank, Vision, Temporary, Legion, …) come
from the printed keywords and are not re-implemented. Catalog keywords that a card only grants
("Your Mechs have [Deflect]") or only has in effect text are marked not intrinsic
(`{ kind: "keyword", keyword, value: 0 }`, 727.1.b); effect-text keywords and Might Bonuses of
Equipment are host-targeted passives (718.3/718.4).

## Engine reproductions (all fixed in R4)

The bodies live in `packages/rules/test/cards/sfd/bugs.test.ts` and stay as regression coverage. No
`[BUG]` test is skipped. R4-engine lane B fixed Repeat execution and per-execution choices (Feral
Strength and the Repeat spells are `implemented`); lane C fixed delayed replacement choices
(Counter Strike); lane D fixed Equip, Weaponmaster, Quick-Draw, Deploy and attached Effect Text
(Doran's Blade, Combat Chef, Long Sword). R4-engine lane E added the facedown-play provenance
(`data.playedFromFacedown`, 811.6); Edge of Night's own trigger is still not scripted (see its
status row).

## Lane conflicts

- Janna, Savior — scripted in R4. `test/rules/reaction-permanents.test.ts` (R1, outside this lane) uses her as a vanilla Reaction unit, and her play trigger changes that test's Priority sequence; that test now registers a vanilla override for her (as it already does for Treasure Hunter).

## Card data issues

- Bonds of Strength — catalog text "Give two friendly units each +1 [Might]" has no duration and no closing period (likely truncated); scripted `manual` until confirmed.
